COMANDOS DEL BOT (7 IMPLEMENTADOS)
================================================================================

1. !help
   Muestra lista de comandos disponibles

2. !ping
   Responde "Pong!" para verificar actividad

3. !echo <mensaje>
   Repite el mensaje en el canal

4. !info
   Muestra nombre, versión y uptime del servidor

5. !contador [reset]
   Incrementa contador persistente o lo reinicia

6. !hora
   Muestra fecha y hora actual (YYYY-MM-DD HH:MM:SS)

7. !usuarios
   Lista usuarios en el canal con prefijo @ para operadores

ESTRUCTURA TÉCNICA
================================================================================

ARQUITECTURA DEL BOT:
  
  main_bonus.cpp
       ↓
    [fork()]
       ├─ Proceso padre (Server) ← Acepta clientes IRC normales
       └─ Proceso hijo (Bot)
            ├─ socket() → connect() a localhost:puerto
            ├─ Autenticación (PASS, NICK, USER)
            ├─ JOIN #general, #random
            └─ Loop infinito escuchando PRIVMSG con "!"
                 ├─ Parse comando
                 ├─ Ejecuta _cmdXXX()
                 └─ Broadcast respuesta

COMUNICACIÓN:
  Cliente ─┐
  Cliente ─┼─ Server (poll) ─── [sin bot: fin]
  Cliente ─┘
            │
            └─ Bot (proceso hijo)
                 └─ Responde a comandos !xxx

INSTRUCCIONES PARA EJECUTAR
================================================================================

PASO 1 - Compilación:
  $ cd /home/carbon/irc
  $ make clean
  $ make bonus

PASO 2 - Iniciar servidor:
  $ ./ircserv_bonus 6667 password

PASO 3 - Conectar cliente (en otra terminal):
  $ nc localhost 6667

PASO 4 - Autenticarse:
  PASS password
  NICK usuario
  USER usuario 0 * :Usuario
  JOIN #general

PASO 5 - Usar bot:
  PRIVMSG #general :!help
  PRIVMSG #general :!ping
  PRIVMSG #general :!info
  PRIVMSG #general :!contador
  PRIVMSG #general :!hora
  PRIVMSG #general :!usuarios

PASO 6 - Salir:
  QUIT
